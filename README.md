# NetraOS

NetraOS is a small web-based desktop project inspired by operating systems.
It runs directly in the browser and includes draggable windows, a live clock, and simple built-in apps.
Created using [Hack Club WebOS](https://jams.hackclub.com/batch/webOS).

## Features
- Draggable windows
- Live clock in the top bar
- Welcome window
- Calculator app
- Notes app with local saving
- Custom visual style

## How to use
1. Open the project in your browser.
2. Click app names in the dock to open windows.
3. Drag windows by their title bars.
4. Use the calculator and notes app as needed.
